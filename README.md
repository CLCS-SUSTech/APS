# AutoPeriod of Surprisal

This repository contains the experiment code for [Identifying the Periodicity of Information in Natural Language](https://aclanthology.org/2026.acl-long.52/).

## Example

From the repository root, install the dependencies and run the example:

```bash
python -m pip install -r requirements.txt
python example.py
```

The example loads the included `wsj_2380_nll.npy` and prints the detected period results.
